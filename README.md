# 새로 생긴 가게 지도 (store-strategy)

행정안전부 지방행정 인허가 공공데이터로 동네에 새로 생긴 가게(휴게음식점·일반음식점)를 매일 모아 지도용 자료로 만든다. 대상: 수도권 66개 지자체(서울 25구, 경기 31시군, 인천 10군구, `scripts/지자체_수도권.json`).

## 매일 하는 일

GitHub Actions가 매일 04:37(한국 시간)에 `scripts/매일갱신.py`를 돌리고 결과를 `data/`에 커밋한다.

1. 인허가 API에서 지자체마다 지난 실행 이후 바뀐 건만 받는다(최근 90일 인허가분). 처음 보는 지자체는 90일 치 전부. 한 번에 못 끝내면 남은 지자체·업종 조회는 다음 실행으로 넘긴다.
2. 임시 영업을 뺀다: 폐업, "한시적" 표기, 푸드트럭, 규모 0인 행사장·행사 키워드 주소, 지도에 '팝업'으로 등록된 매장.
3. 업종을 정한다: 원자료 업태 → 프랜차이즈 사전 → 상호 키워드 → 공정위 가맹 브랜드 사전 → 카카오 로컬 → 네이버 지역 검색.
4. 좌표를 채운다: 원자료 좌표 → 브이월드 → 카카오 주소 검색.
5. `data/map/{지자체코드}.json`으로 내보낸다.

## 자료

| 파일 | 내용 |
|---|---|
| `data/map/index.json` | 지자체 목록, 지자체별 가게 수 |
| `data/map/{지자체코드}.json` | 지자체별 지도용 가게 목록 |
| `data/shops/{지자체코드}.json` | 관리번호별 원자료와 판정 결과(누적) |
| `data/좌표_캐시.json`, `data/업종조회_캐시.json` | 다시 묻지 않으려고 저장한 조회 결과 |
| `data/상태.json` | 지자체·자료별 마지막 실행일 |

지도용 항목: 이름, 업종, 업종근거, 원업태, 인허가일, 주소, 위도, 경도, 좌표출처, 관리번호.

## 키

저장소 Settings → Secrets and variables → Actions에 아래 이름으로 넣는다. 코드와 자료에는 키를 적지 않는다.

`DATA_GO_KR_KEY`(필수), `KAKAO_REST_KEY`, `NAVER_API_KEY_ID`, `NAVER_API_KEY`, `VWORLD_KEY`

## 출처

행정안전부 지방행정 인허가 데이터(공공데이터포털), 공정거래위원회 가맹사업 정보, 카카오 로컬 API, 네이버 검색 API, 브이월드.
